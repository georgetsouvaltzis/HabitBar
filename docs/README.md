# Habit Bar Documentation

This directory contains the working documentation for Habit Bar. It is meant to
stay close to the current implementation and product direction.

## Documents

- [Product](product.md): user-facing scope, core flows, and non-goals.
- [Architecture](architecture.md): package layout, app boundaries, and data flow.
- [Habit Rules](habit-rules.md): selected-day tracking, completion, streak, and
  notification rules.
- [UI Design](ui-design.md): visual direction for the menu bar popover, habit
  cards, history grid, and editor.
- [Development](development.md): build, run, test, and local verification
  commands.

## Source Of Truth

`GOAL.md` remains the high-level target definition. The docs in this directory
explain how that target maps to the current codebase.
