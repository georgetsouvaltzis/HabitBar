# Changelog

All notable changes to HabitBar are documented in this file.

This project follows Conventional Commits for commit messages.

## Unreleased

- Added repository contributor guidelines in `AGENTS.md`.
- Added a project README with feature overview, requirements, build commands,
  test commands, and project layout.
- Removed the original planning-only `GOAL.md` from the repository.

## 2026-05-17

- Added the initial SwiftPM macOS app structure.
- Added `HabitBar`, `HabitBarCore`, and `HabitBarUITestRunner` targets.
- Added menu-bar habit tracking flows for creating, editing, completing,
  archiving, restoring, and deleting habits.
- Added local JSON persistence, habit rule calculations, notification planning,
  and unit tests.
- Added local scripts for building, launching, release verification, and UI smoke
  testing.
- Added documentation for product scope, architecture, habit rules, UI design,
  and development workflow.
